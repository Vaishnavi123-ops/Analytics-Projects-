📊 Customer Churn Prediction & Decision Impact Analysis

Project Overview
This project focuses on analyzing customer churn data to understand why customers leave a company and how this information can help in improving customer retention.

Objective
Study customer behavior related to churn
Build a model to predict customer churn
Evaluate the model using suitable performance metrics
Use the results to support business decisions

Dataset Used
Customer churn dataset containing customer details and service usage information
Target variable: Churn (Yes / No)
Only the original raw dataset is stored. All data cleaning and processing were done inside the notebook.

Approach
Cleaned and prepared the data using Python (Pandas, NumPy)
Performed basic exploratory analysis to understand churn patterns
Built a Logistic Regression model to predict churn
Evaluated the model using accuracy, precision, recall, F1-score, and confusion matrix
Analyzed the results from a business point of view

Results & Observations
The model was able to capture important churn patterns
Some churn customers were missed, which highlighted business risk
The analysis showed that accuracy alone is not enough to judge model performance
Created powerbi dashboards

Business Understanding
Losing a churn customer results in revenue loss, while wrongly warning a loyal customer only increases effort. Therefore, the results were interpreted with focus on business impact rather than only model accuracy.

Tools Used
Python
Pandas
NumPy
Matplotlib
scikit-learn
Jupyter Notebook

Conclusion
This project helped in understanding how machine learning models can be used to support customer retention decisions by combining data analysis, model evaluation, and basic business understanding.
